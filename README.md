# 元素分数转换工具（Element Converter）

质量分数（wt%）↔ 摩尔分数（mol%）双向互换计算器，内置 118 种元素周期表选择与独立的「元素性质百科」页面（浏览、详情、横向对比）。

## 功能

- **分数互换计算**：从周期表单击选元素、输入 wt% 或 mol%，一键互换；展示完整公式与逐步计算过程，支持 TXT 结果导出
- **归一化计算**：成分总和 ≠ 100% 时可勾选，按比例自动缩放至 100%，结果中呈现归一化前后对比列
- **元素性质百科**（`table.html`）：周期表浏览 / 搜索 / 分类筛选；单元素 21+ 项物化性质详情（密度、熔沸点、比热容、热导率、电负性、电离能、三种半径、电子排布与壳层、氧化态、晶体结构等）；2–6 个元素横向对比表 + 数值条形图 + **玻尔模型动效**（各电子层异速反向旋转）
- **5 套主题**：深灰 / 浅亮 / 海洋 / 森林 / 日落，全站 CSS 变量驱动

## 数据来源

- 相对原子质量：IUPAC 2024 标准原子量（CIAAW）
- 物化性质：CRC 化学手册 / IUPAC；共价半径采用 Pyykkö & Atsumi (2009) 单键共价半径（与 zh.webqc.org 一致）
- 部分合成元素无可靠实测数据，如实标注「未知 / (预)」

## 技术栈

纯前端静态应用：Vite 7 + TypeScript 5 + Tailwind CSS 3，零运行时依赖，构建产物为纯静态文件（`dist/`），可部署到任意静态托管（GitHub Pages、EdgeOne Pages 等）。

## 本地开发

```bash
pnpm install        # 或 npm install
pnpm dev            # 开发服务器
pnpm ts-check       # TypeScript 类型检查
pnpm build          # 构建到 dist/
```
